# Finance Manager

> 🚧 Project in development

A personal finance manager to track income and expenses, with monthly summaries and AI-powered automatic categorization of transactions.

## Tech Stack

- **Backend:** Java 21, Spring Boot, Spring Data JPA
- **Database:** H2 (development), PostgreSQL (planned)
- **Frontend:** Angular (planned)
- **AI:** Spring AI (planned)

## Features

- [ ] CRUD for transactions and categories
- [ ] Monthly summary (income, expenses and balance)
- [ ] Spending chart by category
- [ ] AI-suggested category based on the transaction description

## Running locally

Requirements: Java 21

```bash
./mvnw spring-boot:run
```
